# Cloudinary Media Processing

Cloudinary is used to generate the final branded QR image used throughout the DropSpot Automation Platform.  
It acts as a dynamic image compositor, combining:

- the raw QR code generated by Apps Script  
- a branded border frame  
- the DropSpot site ID number  

This produces a consistent, professional, print‑ready QR asset without storing multiple versions.

---

## How the Workflow Operates

### 1. QR Code Generation
Apps Script generates a raw QR code (PNG) using the Google Charts API.

### 2. Upload to Cloudinary
The raw QR image is uploaded to Cloudinary using a simple HTTP POST request.

Cloudinary returns:
- a `public_id`
- a secure CDN URL
- metadata for transformations

### 3. Cloudinary Transformation
A transformation URL is constructed to combine:

- **Layer 1:** Branded border frame  
- **Layer 2:** QR code (scaled and centered)  
- **Layer 3:** Site ID text overlay  

Cloudinary handles:
- resizing  
- centering  
- compositing  
- text rendering  
- output formatting  

### 4. Final Image Returned
Apps Script receives the final composite image URL and inserts it into the PDF.

---

## Example Transformation (Conceptual)

> Note: Replace with your actual Cloudinary URL and transformation parameters.

```
https://res.cloudinary.com/<cloud>/image/upload/
l_<qr_public_id>/w_800,h_800,c_fit/
l_text:Arial_80_bold:<SITE_ID>/g_south,y_50/
v1/frame_template.png
```


This transformation:

- loads the QR as an overlay  
- fits it inside the frame  
- adds the site ID text  
- outputs a single merged PNG  

---

## Why Cloudinary?

### ✔ No manual image editing  
Everything is generated dynamically.

### ✔ Consistent branding  
Every DropSpot QR looks identical.

### ✔ No storage bloat  
Only the raw QR is stored; the final composite is generated on demand.

### ✔ Fast CDN delivery  
Cloudinary serves optimized images globally.

### ✔ Easy to update  
Changing the border frame or text style updates **all future QR codes** instantly.

---

## Where Cloudinary Is Used

- In `code.gs` during PDF generation  
- In the QR creation workflow  
- Anywhere the final branded QR is required
